이 저장소의 홈페이지 UI/UX 작업에 항상 적용한다. 우선순위는 **가독성 → 디자인끼리의 조화 → 장식** 순이다.

## 칸 나누기 제한

- 정보를 나눌 때는 먼저 **여백, 글자 크기·굵기, 정렬**로 구분한다. 카드·박스·테두리·배경색 상자는 그다음 수단이다.
- 카드 안에 카드를 넣지 않는다.
- 한 화면에 카드 그리드는 최대 1개. 같은 모양의 박스를 3개 이상 나란히 놓고 싶으면, 목록이나 표, 혹은 여백으로 구분한 섹션으로 대신할 수 있는지 먼저 검토한다.
- 모든 섹션에 테두리나 그림자를 두르지 않는다. 섹션 구분은 넉넉한 세로 여백(섹션 간 최소 64px, 모바일 40px)으로 한다.
- 둥근 카드 + 왼쪽 색 테두리, 아이콘+제목+설명 3단 카드 반복 같은 전형적인 AI 패턴을 쓰지 않는다.

## 가독성

- 본문 16px 이상, 줄 간격 1.6~1.8 (한글 기준).
- 본문 한 줄은 한글 약 40~45자(`max-width: 34em` 안팎)를 넘지 않는다.
- 본문 단락은 왼쪽 정렬. 가운데 정렬은 짧은 제목에만.
- 글자 대비는 WCAG AA(본문 4.5:1) 이상. 순수 검정(#000) 대신 짙은 회색 계열을 쓴다.
- 글꼴은 최대 2종, 굵기는 최대 3단계.

## 조화

- 색, 글자 크기 단계, 여백, 모서리 둥글기, 그림자를 `:root`의 CSS 변수로 먼저 정하고, 그 밖의 값은 쓰지 않는다.
- 여백은 4/8px 배수 체계를 따른다.
- 강조색은 1개. 화면 면적 기준 60(바탕)·30(보조)·10(강조) 비율을 지킨다.
- 모서리 둥글기와 그림자는 화면 전체에서 한 가지 규칙만 쓴다.

## 작업 후 점검

UI를 바꾼 뒤에는 `optik-score`나 `optik-layout-audit`로 점검하고, 카드 중첩과 가독성 문제를 먼저 고친다.
